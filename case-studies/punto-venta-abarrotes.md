# Punto de venta para abarrotes

## Problema

Consultar y gestionar clientes, productos y crédito desde una aplicación de escritorio y móvil, con importación de catálogo.

## Solución

Una aplicación multiplataforma guarda información localmente y permite importar datos desde CSV.

## Participación

Desarrollo móvil y persistencia local.

## Funciones

- Clientes, productos y crédito.
- Importación CSV.
- Eliminación lógica.
- Respaldos y almacenamiento local.

## Tecnologías

.NET MAUI, C# y SQLite.

## Privacidad

Datos de muestra ficticios. No se publican bases de datos ni registros reales.
