# Sistema comercial de joyería

## Problema

Administrar productos, clientes, ventas e inventario junto con usuarios, roles, cortes de caja y reportes.

## Solución

Un sistema web reúne catálogo, movimientos y consultas comerciales en módulos conectados.

## Participación

Desarrollo full stack de vistas administrativas y comunicación con APIs REST.

## Funciones

- Productos y clientes.
- Ventas e inventario.
- Usuarios y roles.
- Cortes de caja y reportes.

## Tecnologías

React, TypeScript, APIs REST y MySQL.

## Privacidad

El mockup usa una identidad visual original y datos recreados, sin nombre ni logotipo de empresa.
