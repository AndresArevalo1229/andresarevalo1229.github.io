Resumen

Contribuí al frontend de un portal desarrollado en equipo con React y TypeScript.

Mi participación

  • Implementé un cliente API tipado y pantallas de búsqueda y filtros de especialistas.
  • Desarrollé el recorrido de reserva y consulta de citas con estados de carga, vacío y error.
  • Amplié los ajustes del perfil y corregí su actualización y recuperación de fotografía.

Reto técnico

Convertir las respuestas de la API en estados de interfaz comprensibles durante la búsqueda y la reserva. Mis aportaciones corresponden a cambios concretos del portal; la autenticación, agenda y pagos base conservan la autoría del equipo.

Tecnologías

React, TypeScript, React Router, Fetch y APIs REST.

Interfaces originales anonimizadas

Copias de las vistas de demostración, recortadas o cubiertas de forma determinista para excluir marcas e identidades. Conservan los controles visibles; los datos son ficticios.

Recreaciones esquemáticas

Alcance de las recreaciones

Las imágenes son recreaciones esquemáticas propias basadas en las vistas documentadas. Los datos son ficticios y la presentación se simplificó para excluir marcas e información confidencial. No son capturas de una aplicación ejecutada ni demuestran operaciones reales.
